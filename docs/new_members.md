# New Members

Follow the steps below in order to join the AMP Lab. Please do not continue to the next step until instructed.

## 1. Review the AMP Lab Membership Guidelines

Before preparing a Project Proposal, read the AMP Lab Membership Guidelines. This document explains:

- Membership eligibility
- Project rules and limitations
- Funding requirements
- Expectations for AMP Lab members

<a class="btn" href="/general_documentation/AMP%20Lab%20Membership%20Guidelines.pdf">

    AMP Lab Membership Guidelines
</a>

If you meet the eligibility requirements and your proposed project follows the guidelines, continue to Step 2.

## 2. Complete a Project Proposal

Create a brief Project Proposal presentation composed of:

1. **Project Overview**
    - Clearly state the goal of your project.
    - Include visuals such as block diagrams, flowcharts, CAD models, circuit diagrams, or other system-level illustrations.

2. **What You Hope to Learn**
    - Explain the technical knowledge, skills, or experience you hope to gain from the project.

3. **Components and Estimated Cost**
    - List the major components or materials required.
    - Include estimated individual costs and a total project cost.

4. **Timeline**
    - Outline a realistic timeline for the project.

The presentation should take no longer than **15 minutes**.

Once your presentation is ready, schedule a Project Proposal meeting with the AMP Lab team:

<a class="btn" href="/soldering/booking">

    Schedule a Project Proposal
</a>

**Do not continue to Step 3 until your Project Proposal has been reviewed and approved.**

## 3. Complete New Member Onboarding

After your Project Proposal has been approved, complete the remaining onboarding requirements.

### Create Your Project GitHub Repository

For now, use the AMP Lab Sample Project repository to create the GitHub repository for your approved project.

<a class="btn" href="https://github.com/Amp-Lab-at-VT/SampleProject/fork">

    Sample Project
</a>

Rename the repository for your project, update the `README.md`, and maintain the repository throughout the semester to document your work and progress.

**Too confusing?** Git can take some time to learn. Check <a href="/beginners_guide">this tutorial</a> for help getting started.

Once your GitHub repository is created, complete the AMP Lab New Member Onboarding Form and follow the instructions provided there for the remaining onboarding requirements.

    AMP Lab New Member Onboarding Form
</a>

## 4. Swipe Access

After your onboarding form and required documents have been reviewed and verified, AMP Lab leadership will submit your information for AMP Lab swipe access.

**You do not need to submit a separate swipe access request.**

You will be notified once your onboarding requirements have been completed and your access request has been processed.
